## Conditions and held-out gate

Every OpenAI panel uses 20 turns, 16,384 inclusive output tokens, one repeat, and the independently versioned v0.9 common 600-second provider deadline. The new transport is the legacy implementation with only that deadline changed; historical v0.7c/v0.8 remain 300 seconds. Cross-generation task, source, metric and deadline differences preclude clean score deltas. Provider error is unscored, scored coverage is explicit, output-limited traces retain raw grades but reject clean contrasts.

Every paid panel prospectively selects the first case in each family for its split (case offset0, one per family), producing three matched anchors. This index-based choice precedes every model output. Second cases remain unused in this registered loop; any extension needs a new prospective registration.

Exact source/prompt/corpus/model hashes and task IDs will be registered before inference. Serial controller dispatch creates a receipt before each child call and preserves native raw runs. No held-out model output is read before a separately committed final release after development audit; the source, harness, task IDs, limits and model configuration must remain those registered. Engineering source inspection of held-out construction is not a held-out model run. No new source-format ablation is included in this budget; the prompt ablation is labeled separately and never pooled as another benchmark task.

All empirical conclusions need source consistency, meaningful operation coverage, repeatability and expert review. Three cases across three synthetic families give coarse, correlated descriptive evidence, not general model rankings or a validated insurance capability score.
