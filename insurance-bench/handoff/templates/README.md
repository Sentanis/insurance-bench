# Matched self-run external handoff

These answer-free operator templates target exactly Anthropic Fable6/Opus5.5/Sonnet5.5/Haiku5.5 and Google Gemini3.7Flash/Gemini3.8Flash at low/high/max. They assert neither API availability nor verified native effort support. Gemini3.8 max is unsupported; supported high-equivalent is a distinct condition.

Build a frozen package with: npx tsx scripts/build-insurance-bench-handoff.ts --root FROZEN_ARTIFACT_ROOT --out FROZEN_ARTIFACT_ROOT/handoff/NEW_DIRECTORY
Without --root the builder emits generic templates under insurance-bench/handoff only, no tasks/notices, and cannot support execution. Full input packages are restricted to FROZEN_ARTIFACT_ROOT/handoff outside the repository. With --root it validates the current freeze, copies only public static request prompts/raster attachments and full hashed notices; no registration/private grader paths, rubrics, answers, actor transcripts or future native state are copied. Official few-shot demonstrations already inside the frozen LegalBench prompt remain source input. The full Harvey MIT notice is scoped to Harvey; the exact CC-BY attribution notice applies to the LegalBench subset. No blanket MIT/CC0 or other new public-data/code license is granted for our original synthetic work. User-local sharing with the requested providers is authorized; published scores do not authorize public hosting of inputs.

The external return is evidence for later controller review, not a native Run, grade or admissible full score. All29 static tasks are12 fresh requests: one18-case LegalBench batch, three Harvey and eight original synthetic tasks. The three native episodes require the coordinator. Use a separately reviewed/cohort-registered SelfRunTransport adapter; never redirect an OpenAI-profile request to Claude/Google and report OpenAI identity.

Adapter contract (type-only): SelfRunTransport(request: CodexSubagentRequest): Promise<CodexSubagentResult>. Preserve request identity/prompt/image bytes/deadline, exact configured/observed native model, actual effort configuration, final-answer phase/block selection, usage or null, immutable events and confirmed termination. Reject tools/fallback/substitution; return a transport gap for unsupported controls. Current Codex result has no observed-effort field: a later adapter/cohort must bind supplemental actual effort evidence before a matched-effort claim. Do not flatten commentary/final blocks.

No external cohort registration, Claude/Google transport adapter, judge dispatch or full-profile publication import is implemented here. runNativeHandoffBridge is a runnable controller exchange with an explicitly supplied external transport and separately hash-bound model/effort mapping binding, not a default model dispatch. A self-hash is not independent approval; the caller must prospectively review/register the external adapter/cohort and its exact native IDs before execution. Existing coordinator validates fixed OpenAI profiles. The actual external adapter/cohort must be separately implemented/reviewed/frozen before native runs. Use runNativeHandoffBridge({root, profileId, taskId, binding, outputDir, transport}); persist outputs only in the private .tmp/insurance-bench/external-selfrun tree. Adapter responses must include nativeEffort parameter/value/evidence metadata matching the binding, observed model identity, immutable request events and confirmed termination. Missing metadata produces a transport gap, not a fabricated model score. Portable static returns can be structurally validated by validateHandoffReturn or npx tsx scripts/build-insurance-bench-handoff.ts --manifest USER_LOCAL_PACKAGE/manifest.json --return PRIVATE_RETURN.json; this does not write results or run private graders.
