A new, adapted measurement

This cohort combines a public LegalBench subset, adapted Harvey legal artifacts, original fictional OCR and professional tasks, and fresh synthetic stateful insurance episodes. It does not report original OmniDocBench, GDPval, full LegalBench, or native Harvey benchmark scores; it does not establish professional validity or an index rank.

The published-reference index remains a separate research view. Other providers appear only when exact model identity, effort configuration, and full task coverage are verified.

Model identity: rows name the model and effort configured in the run, with provider evidence where available.

Effort controls: each call used an explicit CLI reasoning-effort override while user configuration was ignored; receipt admission checks the requested level against the frozen profile. The provider does not return independent confirmation of effective effort. Ultra is excluded because it enables automatic task delegation and is not a comparable single-agent setting across these four models.

    Frozen conditions and interpretation

    LegalBench uses one fresh batch in frozen order per profile. Other static tasks use a fresh request per task. Stateful episodes start fresh and carry the chronological public interaction history between turns. No retries or fallback models are admitted.

    Two fixed blinded juries grade valid adapted Harvey artifacts; original criteria are evaluated with all-pass scoring per jury and their mean. Other tasks use all-pass grading. Task means form each component; fixed component weights form a complete composite. Expert validation remains open.

    Each native episode permits 20 turns, with up to 20 actions per response (400 actions maximum per episode). Request timeout: 600 seconds. Maximum simultaneous profiles: 3. Elapsed time sums candidate and jury request durations and is not cohort wall-clock time. Costs are unavailable unless an explicit numeric cost is reported.

    Only public headline metrics are exported. Candidate transcripts, answers, expected outputs, hidden rubrics, source fixtures, and grader diagnostics remain outside this static site.
